# Finpulse

Plateforme de gestion financière basée sur une architecture microservices.

## Structure

- **Backend/** : un projet par microservice (Entreprise-Tiers, Facturation, Tresorerie, Risques, Notifications)
- **Frontend/** : application web
- **Documentation/Presentation** : supports de présentation
- **Documentation/Diagrams** : diagrammes (UML, architecture...)
